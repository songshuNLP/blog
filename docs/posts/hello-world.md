# 开篇：为什么要写这个博客

你好，我是**兔老板工作室**，互联网大厂高级算法工程师，《图深度学习从理论到实践》《快速部署大模型》作者。

从今天起，我会在这个 GitHub 博客里持续更新技术文章。这个博客有几个特点：

## 为什么放在 GitHub？

- **源码即内容**：每篇文章就是一个 markdown 文件，所见即所得
- **方便交流**：可以在 Discussions / Issue / Pull Request 里参与讨论
- **开放沉淀**：文章永久归档，对搜索引擎友好

## 我会写什么

1. **大模型**：部署、微调、RAG、Agent 等落地实践
2. **图深度学习**：推荐、风控、广告、搜索里的图算法
3. **编程实战**：源码级项目拆解、架构设计、工程效率
